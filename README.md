# Carlos Quintero Website

A personal website built with Next.js, React, and Tailwind CSS, showcasing the portfolio and projects of Carlos Quintero.

## How to Use

1. Clone the repository: `git clone https://github.com/Gabrieli2806/WebsiteCarlos.git`
2. Navigate to the project directory: `cd WebsiteCarlos`
3. Install dependencies: `npm install`
4. Run the development server: `npm run dev`
5. Open your browser and go to `http://localhost:3000` to view the website.
